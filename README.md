# Visual Programming

## Windows Forms Applications - C# (.NET Framework)

This repository contains solved exercises, laboratory assignments, and practice projects developed in C# using Windows Forms and the .NET Framework. The projects were created while learning desktop application development, object-oriented programming, graphical user interface design, and event-driven programming.

The repository includes different types of Windows Forms applications, focusing on implementing application logic, working with forms and controls, handling user interaction, animations, timers, custom classes, drawing, and various programming concepts through practical exercises.

All projects were developed in Microsoft Visual Studio using the Windows Forms framework in C#.

## Topics Covered

- Windows Forms development
- Event-driven programming
- Object-oriented programming (OOP)
- GUI and user interaction
- Timers and animations
- Drawing and graphics
- Working with multiple forms
- Collections and custom classes
- Application logic and problem solving

## Technologies Used

- C#
- Windows Forms
- .NET Framework
- Visual Studio
